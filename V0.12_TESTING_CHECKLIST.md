# XR1 Studio v0.12 Testing Checklist

## Layout

- [ ] Media bin, viewer and inspector align to the same height.
- [ ] Timeline spans the full editor width below the workbench.
- [ ] Timeline tools appear directly above the transport and ruler.
- [ ] No tool labels overlap at 1920px, 1440px or 1280px widths.
- [ ] At narrow widths, tool groups scroll horizontally without shrinking buttons.

## Tools

- [ ] Select, Trim, Blade and Hand active states are clearly visible.
- [ ] Standard and Ripple trim modes switch correctly.
- [ ] Trim Start to Playhead and End to Playhead only enable with a selected clip.
- [ ] Undo, Redo, Split, Audio, Lift and Ripple Delete remain functional.
- [ ] Snap and Ripple scope toggles use restrained active styling.

## Timeline

- [ ] Track headers remain aligned with their lanes while scrolling.
- [ ] Ruler starts immediately after the 155px track header.
- [ ] Playhead and snap guides align with clip edges.
- [ ] Timeline zoom controls remain aligned in the transport row.
