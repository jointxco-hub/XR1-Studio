# XR1 Studio v0.13 — Deep Clean

## Fixes and polish

- Cleaned the timeline top bar so controls no longer get clipped on narrower widths.
- Added dedicated left and right control groups with safer wrapping and horizontal overflow handling.
- Improved zoom controls, FPS readout and fit button alignment.
- Added a stable `addTimelineMarker()` action with success notifications.
- Timeline markers are now easier to see and click on the ruler.
- Clicking a marker seeks to it and shows its label.
- Double-clicking a marker removes it.
- Improved control spacing, disabled states, and responsive behavior across the editor.
- Reduced panel crowding and tightened the edit workspace presentation.
