# XR1 Studio v0.12 — Timeline Layout and Alignment

## Editor layout

- Moved Select, Trim, Blade and Hand into a dedicated dock directly above the timeline.
- Replaced the oversized top toolbar with a compact sequence utility bar.
- Rebalanced the media bin, sequence viewer and inspector columns.
- Standardised panel heights, spacing, borders and corner radii.
- Improved responsive behaviour for desktop, laptop and narrow layouts.

## Timeline controls

- Standard and Ripple trim modes remain available beside the primary tools.
- Trim Start to Playhead and Trim End to Playhead are grouped with trimming controls.
- Undo, Redo, Split, Extract Audio, Lift, Ripple Delete, Group, Ungroup and Snap now sit in the timeline dock.
- Active tools use a single strong lime state; secondary toggles use a restrained outline state.
- Track controls and transport controls use consistent vector icons and alignment.

## Export

- Sequence edit-plan schema updated to version 6.
