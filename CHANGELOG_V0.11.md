# XR1 Studio v0.11 — Professional Trimming

## What's new

- Rebuilt the edit toolbar into a clearer, top-mounted timeline control bar inspired by professional NLE layouts.
- Upgraded the core tool buttons with clearer vector icons and stronger contrast for the Apple/Tesla-inspired XR1 look.
- Added a dedicated trimming cluster with:
  - Standard trim mode
  - Ripple trim mode
  - Trim selected clip start to playhead
  - Trim selected clip end to playhead
- Improved top-level editor controls for undo, redo, split, extract audio, lift, ripple delete, grouping and snapping.
- Made timeline utility icons more visible in the track header and top transport bar.

## Notes

- Ripple mode ripples following clips on targeted, unlocked tracks based on the selected clip's end-point change.
- Existing v0.10 trim foundation behavior remains intact.
